# Changelog

## v0.1.0

- Consolidated the mod into a single install component.
- Curated the collection to **372 custom portraits**: 212 male and 160 female.
- Included 250 Main Collection portraits, 23 Icewind Dale II portraits, 89 Garion portraits, and 10 Photoshopped Variations.
- Kept the 59 IWDEE zoomed vanilla sidebar replacements inside the same component, installed only on IWDEE.
- Renamed all selected custom portrait resrefs to clean `SIPM###` / `SIPF###` identifiers.
- Preserved male/female separation in both the vanilla Enhanced Edition UI and Infinity UI++.
- Preserved non-zoomed `L` portraits for character creation and Character Record, with zoomed `M` portraits for the gameplay sidebar.
- Added support for BG:EE, BG2:EE, EET, and IWDEE.
